# Gramartico

Gramartico is a focused writing assistant that helps people improve correctness, clarity, tone, and confidence as they write.

## Features

- Distraction-free document editor with live word and reading-time counts
- Actionable grammar and clarity suggestions
- Live writing score and completion state
- Audience, formality, and tone goals
- Responsive navigation for desktop and mobile

## Run locally

```bash
npm start
```

Then open <http://localhost:4173>.

## Tests

```bash
npm test
```
